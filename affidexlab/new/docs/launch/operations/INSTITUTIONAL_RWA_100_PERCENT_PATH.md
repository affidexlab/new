# Institutional/RWA path to 100% launch readiness

DecaFlow-owned infrastructure means DecaFlow runs the identity registry, compliance rules, risk oracle, operator runbooks, Safe/multisig administration, evidence retention, investor checks, and issuer reporting. It does not remove the need for external legal opinions or regulated KYC data sources; those are inputs DecaFlow must operationalize.

Required gates: counsel-approved offering templates, DecaFlow KYC/KYB/accreditation operations, production identity/risk oracle operators, Safe/multisig per chain, final contract deployment scripts, deployment addresses, post-configuration security review, issuer onboarding SOP, regulator export pack, and disaster recovery runbook.
