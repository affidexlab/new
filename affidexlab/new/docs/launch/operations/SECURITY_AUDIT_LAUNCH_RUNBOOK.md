# Security Audit 100% launch readiness runbook

DecaFlow can sell audits when every engagement follows this owned process: signed scope, frozen commit hash, standard severity taxonomy, manual review checklist, automated test review, draft QA, client remediation window, fix verification, final PDF, and Shield handoff. The backend now stores audit delivery templates in `audit_delivery_templates` so operations are not just tribal knowledge.

Minimum staffing before broad launch: lead auditor, backup reviewer, report QA owner, client success owner, and incident escalation owner. Do not promise turnaround times the team cannot staff.
